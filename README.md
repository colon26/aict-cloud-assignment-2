# AICT Cloud Assignment 2

## Project Purpose
This project demonstrates basic Python programming and the analysis of sensor readings using Python.

## Readings
The program stores a collection of readings and calculates:
- Minimum reading
- Maximum reading
- Average reading

## How to Run
1. Download the Python file from this repository.
2. Open Google Colab or any Python IDE.
3. Upload or open the file.
4. Run the code to view the results.
